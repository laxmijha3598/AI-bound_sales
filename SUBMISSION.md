# Submission

## What is included

- Runnable code for the outbound agent.
- `data/starter_leads.csv` with 10 public-source leads, public source URLs, hiring signals, and personalization facts.
- `out/outreach_log.csv` generated by the agent.
- `out/linkedin_queue.csv` generated by the agent for human-reviewed LinkedIn connection notes.
- `SCALE.md` with the 10/week to 1,000/week scaling paragraph.

## How to run the demo

```powershell
.\run_demo.ps1
```

That command generates:

- `out/outreach_log.csv`
- `out/linkedin_queue.csv`

## Real account steps

The code supports real Gmail sends, Gmail reply monitoring, Calendly auto-replies, and Google Sheets sync. These require the sender's own account credentials in `.env`.

I did not include secrets or perform automated LinkedIn sends. LinkedIn is intentionally semi-manual because connection automation can violate LinkedIn's terms and put the account at risk. The agent drafts personalized notes under 300 characters, exports them, and can open profiles for manual sending.

## Commands for authenticated run

```powershell
Copy-Item .env.example .env
# Fill in Gmail, Calendly, and Google Sheet values in .env
python -m sales_agent.cli run --config config.toml --leads data/starter_leads.csv --limit 10 --send-email --sync-sheets
python -m sales_agent.cli linkedin-queue --log out/outreach_log.csv --open-browser
python -m sales_agent.cli watch-replies --config config.toml --log out/outreach_log.csv --sync-sheets
```
